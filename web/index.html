128 KB part; only 0x00000–0x054AE holds data. Reads are split into 256-byte commands and retried, because the device aligns each printed row down to a 16-byte boundary. Byte 0x8D is the power-on privilege level.

Console idle

Vendor HID interface 3 of 14ed:1012, usage page 0xFF00: one 64-byte OUT report and one 64-byte IN report, no report ID. A command is ASCII terminated by NUL, at most 127 characters, split across reports at 64 bytes. Replies are NUL-terminated ASCII with no end-of-reply marker, so this page reads until the endpoint goes quiet. Protocol from hid-protocol.md; block names from data/DSP-Settings-MV7.xml. update is blocked — this page does no firmware upload.

Linux permissions. The browser lists the device from sysfs but opens /dev/hidraw*, which is root-only by default, so the chooser succeeds and the open fails. Give your seat access with a udev rule: SUBSYSTEM=="hidraw", ATTRS{idVendor}=="14ed", ATTRS{idProduct}=="1012", MODE="0660", TAG+="uaccess" — on NixOS put that in services.udev.extraRules. Then sudo udevadm control --reload && sudo udevadm trigger, or replug the microphone. The MV7 shows two hidraw nodes; the one this page wants has a report descriptor starting 06 00 ff.
